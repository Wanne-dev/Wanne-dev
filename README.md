## Proyecto Destacado: BANCA NEN (Proyecto-Nen)

**BANCA NEN** es una plataforma Fintech de inversión asistida por Inteligencia Artificial diseñada bajo una arquitectura de microservicios. Democratiza el acceso a mercados financieros (acciones, criptomonedas, divisas) ofreciendo evaluación de riesgo en tiempo real.

* **Arquitectura de Microservicios:** Separación estricta entre API REST (Node.js/Express), interfaz web (React/Vite), app móvil (React Native) y un servicio de IA (Python/FastAPI).
* **Motor de IA Integrado:** Implementación de modelos de Machine Learning (LSTM, XGBoost) para predecir riesgos operacionales, operando en un entorno aislado y consumido vía endpoints específicos.
* **Transacciones y Seguridad:** Billetera multidivisa con bloqueos optimistas para evitar condiciones de carrera, integración con la pasarela de pagos Wompi y un sistema asíncrono de alertas de anomalías.
* **Infraestructura como Código (IaC):** Entornos estandarizados con Docker Compose para desarrollo local, y configuraciones preparadas para Kubernetes y Terraform en producción.
* **Gestión de Estado Avanzada:** Uso de Zustand en el cliente para evitar re-renderizados innecesarios y TypeORM en el servidor para mantener la integridad de la base de datos PostgreSQL.
